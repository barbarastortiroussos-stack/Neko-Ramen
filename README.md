# 🏮 Izakaya no Entardecer

> Um jogo indie *cozy* de simulação de restaurante japonês desenvolvido em JavaScript puro, HTML5 e CSS.

## ✨ Sobre o Jogo

**Izakaya no Entardecer** convida você a gerenciar um aconchegante e levemente sombrio pub japonês. Atenda os clientes que chegam às mesas antes que a paciência deles esgote, sirva pratos tradicionais e ganhe moedas para expandir seu cardápio em um ciclo (*loop*) relaxante e viciante.

### 🎮 Mecânicas Principais
* **Sistema de Atendimento em Tempo Real:** Clique nas mesas para atender os pedidos dos clientes (como *sushi, rámen, sakê*).
* **Barra de Paciencia:** Cada cliente possui um tempo limite antes de ir embora frustrado.
* **Expediente Dinâmico:** O dia tem duração cronometrada com uma barra de progresso visual.
* **Economia & Progressão:** Ganhe moedas por cada cliente satisfeito para desbloquear novas receitas e itens.
* **Sistema de Diagnóstico e Fallback:** Tratamento de erros robusto em JavaScript para garantir que o jogo nunca quebre silenciosamente na tela do usuário.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído do zero, sem o uso de engines pesadas, focando em performance e domínio da linguagem:
* **HTML5 Semantic:** Estrutura e marcação limpas.
* **CSS3 Custom Properties & Animations:** Estilização com variáveis (`:root`), animações suaves (`keyframes`) e visual *dark-cozy*.
* **JavaScript (ES6+):** Game loop otimizado com `requestAnimationFrame`, gerenciamento de estado global e manipulação dinâmica do DOM.
